# ⚡ Claude & Antigravity Best Skills Framework

> **Le framework modulaire de skills et MCP à 3 niveaux optimisé pour Claude Code et Google Antigravity.** Combine plus de 10 compétences de la communauté dans une architecture sans conflit avec synchronisation en direct via Git Submodules.

---

## 🌟 Caractéristiques principales

* **🧠 Super-Skill Unique (`unified-dev`) :** Regroupe plus de 10 skills sans aucun conflit d'instruction.
* **⚡ 60-70% d'économie de Tokens :** Utilise une architecture **Lazy-Load** à 3 niveaux. Charge les références spécifiques (Web, Mobile, Sécurité, etc.) uniquement en cas de besoin.
* **🔄 Auto-Sync en direct :** Connecté directement aux dépôts open-source d'origine via **Git Submodules**. Mettez à jour toutes les compétences en une seule commande !
* **🛡️ 100% Sécurisé & Prêt pour le Public :** Aucune donnée confidentielle ou clé d'API inscrite en dur.
* **🖥️ Sync Multi-Appareils :** Script d'installation complet (`setup.ps1`) pour une configuration simple sur tous vos PC.

---

## 🚀 Installation Rapide (30 Secondes)

### 1. Cloner avec les sous-modules
```bash
git clone --recursive https://github.com/imyigo/claude-antigravity-skills.git ~/.gemini/claude-antigravity-best-skills
```

### 2. Exécuter le script d'installation
```powershell
cd ~/.gemini/claude-antigravity-best-skills
.\setup.ps1
```

### 3. Mise à jour en un clic
```powershell
.\update-skills.ps1
```
