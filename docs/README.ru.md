# ⚡ Claude & Antigravity Best Skills Framework

> **Масштабируемая, оптимизированная по токенам 3-уровневая модульная структура навыков (skills) и MCP для Claude Code и Google Antigravity.** Объединяет 10+ лучших open-source навыков сообщества в единую архитектуру с живой синхронизацией через Git Submodules.

---

## 🌟 Основные возможности

* **🧠 Единый Супер-Навык (`unified-dev`):** Объединяет 10+ навыков сообщества без конфликтов в единую структуру агента.
* **⚡ Экономия токенов 60-70%:** Использует 3-уровневую **Lazy-Load** архитектуру. Загружает специализированные материалы (Web, Mobile, Security и т.д.) только при необходимости.
* **🔄 Живая Авто-Синхронизация:** Связан напрямую с оригинальными репозиториями через **Git Submodules**. Обновление всех навыков одной командой!
* **🛡️ 100% Безопасность:** Отсутствие приватных токенов и ключей, полностью готов к использованию в публичном доступе.
* **🖥️ Мульти-устройство:** Готовый скрипт развертывания (`setup.ps1`) для быстрой настройки на всех ваших ПК.

---

## 🚀 Быстрый старт (30 секунд)

### 1. Клонирование с субмодулями
```bash
git clone --recursive https://github.com/imyigo/claude-antigravity-skills.git ~/.gemini/claude-antigravity-best-skills
```

### 2. Запуск скрипта установки
```powershell
cd ~/.gemini/claude-antigravity-best-skills
.\setup.ps1
```

### 3. Обновление в один клик
```powershell
.\update-skills.ps1
```
