# ⚡ Claude & Antigravity Best Skills Framework

> **Das ultimative, token-optimierte, 3-stufige modulare Skill- und MCP-Framework für Claude Code und Google Antigravity.** Vereinigt 10+ führende Community-Skills in einer konfliktfreien Architektur mit Live-Git-Submodul-Synchronisierung.

---

## 🌟 Hauptmerkmale

* **🧠 Einzigartiger Super-Skill (`unified-dev`):** Vereint 10+ Community-Skills ohne Konflikte in einer einzigen Framework-Struktur.
* **⚡ 60-70% Token-Einsparung:** Verwendet eine 3-stufige **Lazy-Load**-Architektur. Lädt domänenspezifische Referenzen (Web, Mobil, Sicherheit usw.) nur bei Bedarf.
* **🔄 Live-Auto-Sync:** Direkt über **Git-Submodule** mit den ursprünglichen Open-Source-Repos verbunden. Aktualisieren Sie alle Skills mit einem einzigen Befehl!
* **🛡️ 100% Sicher & Public-Ready:** Keine hartkodierten Zugangsdaten oder sensiblen Daten.
* **🖥️ Geräteübergreifende Sync:** Vollständiges Setup-Skript (`setup.ps1`) für die einfache Installation auf allen PCs.

---

## 🚀 Schnelle Einrichtung (30 Sekunden)

### 1. Klonen mit Submodulen
```bash
git clone --recursive https://github.com/imyigo/claude-antigravity-skills.git ~/.gemini/claude-antigravity-best-skills
```

### 2. Setup-Skript ausführen
```powershell
cd ~/.gemini/claude-antigravity-best-skills
.\setup.ps1
```

### 3. Ein-Klick-Updates
```powershell
.\update-skills.ps1
```
