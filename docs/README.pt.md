# ⚡ Claude & Antigravity Best Skills Framework

> **O framework modular de skills e MCP em 3 camadas otimizado em tokens para Claude Code e Google Antigravity.** Combina mais de 10 habilidades da comunidade em uma arquitetura sem conflitos com sincronização ao vivo via Git Submodules.

---

## 🌟 Principais Recursos

* **🧠 Super-Skill Unificado (`unified-dev`):** Reúne mais de 10 skills da comunidade sem conflitos em uma única estrutura.
* **⚡ Economia de 60-70% de Tokens:** Utiliza uma arquitetura **Lazy-Load** de 3 camadas. Carrega referências específicas (Web, Mobile, Segurança, etc.) apenas quando necessário.
* **🔄 Auto-Sync ao Vivo:** Conectado diretamente aos repositórios originais via **Git Submodules**. Atualize todas as skills com um único comando!
* **🛡️ 100% Seguro e Pronto para Public:** Sem credenciais privadas ou chaves salvas no código.
* **🖥️ Sincronização Multi-Dispositivo:** Script de instalação completo (`setup.ps1`) para fácil configuração em todos os seus PCs.

---

## 🚀 Instalação Rápida (30 Segundos)

### 1. Clonar com Submódulos
```bash
git clone --recursive https://github.com/imyigo/claude-antigravity-skills.git ~/.gemini/claude-antigravity-best-skills
```

### 2. Executar o Script de Configuração
```powershell
cd ~/.gemini/claude-antigravity-best-skills
.\setup.ps1
```

### 3. Atualizações com Um Clique
```powershell
.\update-skills.ps1
```
